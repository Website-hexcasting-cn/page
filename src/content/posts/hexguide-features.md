# HexGuide 手册特色：搜索、图案与玩家笔记

## 搜索手册

我在咒术笔记中加入了一个用于搜索《咒术笔记》内容和条目的文本框。只需输入名称或关键词即可找到相关条目，点击任意结果直接跳转到对应页面，从此再也不用在一堆条目里翻找需要的图案了。

## HexGuide 图案

HexGuide 提供了两个实用图案，方便把咒术记录下来、分享出去：

- **获取文本（copy）**：会把栈顶的 Iota 转换为文本复制到剪贴板，并在聊天栏给出可点击的引用，方便分享或粘贴到书中。同时它会将该 Iota 以 JSON 形式自动保存到游戏目录的 `hexguide/iotas/` 文件夹，之后即可用形如 `iota:hash.json` 的引用在任何地方内嵌显示。
- **保存演示（demo）**：取栈顶的列表 Iota（列表中的每个图案 Iota 会成为演示的一步），生成一份施法演示配置文件，保存到游戏目录的 `hexguide/spellplays/` 文件夹。将生成的文件放入数据包的 `data/hexguide/spellplays/` 目录后，即可在咒术笔记的施法演示页面上播放。

## 玩家笔记

咒术笔记早就不是寻常的笔记，因此也绝非一般的笔可以书写。唯有使用我精心开发的**紫水晶笔**，才能用媒质在纸上铭刻下我作为真理的掌握者神圣的宣言。

> *"道可道，非常道"*

### 紫水晶笔

紫水晶笔的合成很简单：**羽毛 + 任意法杖 + 紫水晶粉**（无序合成）。

使用时，副手持纸，用紫水晶笔右键打开书与笔风格的笔记编辑器；保存时每页消耗一张纸，生成携带**笔记 Iota** 的**笔记残页**。笔记残页实现了 `IotaHolderItem`，可以被 Hex 的读/写法术读写——可以用**书吏之精思**从其中读取出我独创的笔记 Iota。

### 笔记图案

将笔记 Iota 组成列表，便可以用特殊的法术将其纳入到我的笔记之中：

- **纳入笔记（note/import）**：接受笔记 Iota 列表，将其纳入笔记中作为一个章节；
- **维纳斯之精思（note/list）**：返回我纳入的作为章节的所有笔记 Iota 列表所组成的列表；
- **墨丘利之纯化（note/get）**：接受一个索引，返回那个索引所对应的章节的笔记 Iota 列表——此索引就是目录的顺序；
- **删除条目（note/delete）**：接受一个索引，删除那个索引对应的条目。

把笔记残页交给其他玩家，对方用**纳入笔记**法术即可导入到自己的笔记库中。

### 笔记指令

- `/hexguide export <索引>`：把第 `<索引>` 节笔记导出为 JSON（按首页标题命名、格式化换行，存入游戏目录的 `hexguide/notes/`）；
- `/hexguide import <文件名>`：从文件导入笔记（文件名支持 Tab 联想）；
- `/hexguide authority <玩家> <true|false>`：单独配置某玩家的导出/导入权限（默认开启，OP 2 级指令）。
